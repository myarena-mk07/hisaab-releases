🚀 Your first day

  1. Install Hisaab with the button above (install guide).
  2. Switch from Tally: in TallyPrime, turn on the XML port (F1 › Settings › Connectivity: Both, port 9000). In Hisaab: Import › Switch from Tally. Hisaab copies your companies and checks every balance. Tally stays as it is.
  3. Work with the keys you know: V for vouchers, F8 sales, Ctrl+A accept, Esc back.
  4. Keep a copy outside your PC: Alt+Y › Backup & Restore › F9 (Google Drive, OneDrive or a USB folder).
